# 🎮 Python Quiz Game

A fun interactive command-line quiz game developed in Python. The game presents multiple-choice questions, tracks the player's performance, provides instant feedback, calculates a final grade, and saves the highest score for future games.

## 🚀 Features

- 🎯 20 Python-related multiple-choice questions
- 🔤 A/B/C/D answer options
- 🔀 Random question order using the `random` module
- 📊 Score tracking
- ✅ Correct answer count
- ❌ Wrong answer count
- 💬 Instant feedback after every answer
- 📈 Percentage calculation
- 🏆 Grade calculation (A, B, C, D, F)
- 💾 High score saved to a text file
- 🎉 New high score notification
- 🔄 Play again option
- 🛡️ Input validation for invalid answers
